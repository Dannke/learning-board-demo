# Учебная платформа — демо

Прототип доски ученика и рабочего места куратора: 5 колонок (Бэклог → В работе → На проверке → На доработке → Готово), сдача домашки ссылкой, приём или возврат с комментарием, очередь проверки с отдельным списком «ждёт > 24 ч».

Встроенное решение — «темп + ранний сигнал»: плановые сроки модулей вместо ручных дедлайнов, блок «Следующий шаг» у ученика и список «На грани ухода» у куратора (нет движения 5+ дней, доработка без реакции 3+ дня, отставание от плана 7+ дней) с отметкой контакта и статусами «пауза / молчит / ушёл».

Все данные вымышленные и хранятся в localStorage браузера; роль переключается без входа.

```
npm i
npm run dev      # локально
npx vitest run   # тесты логики сроков и переходов (src/domain.test.ts)
```

Логика — `src/domain.ts`, демо-данные — `src/seed.ts`.
